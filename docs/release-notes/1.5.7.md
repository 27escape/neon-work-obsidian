# Neon Work 1.5.7 — release notes

- **Shorter inbox note titles.** A note added from Quick capture or the Inbox card gets its first line as its `title`, now at most 40 characters (cut at a word, with …); the whole text is still in the note.
- **Fixed: inbox notes listed by their file name.** With the Linter plugin's *YAML title* rule on, opening an inbox note set its `title` to the file name (`20261119_123434`), and the Inbox card then showed that. A title that is just the file name is now passed over and the card shows the note's first line.
