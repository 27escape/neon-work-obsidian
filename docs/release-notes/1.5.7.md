# Neon Work 1.5.7 — release notes

- **Shorter inbox note titles.** A note added from Quick capture or the Inbox card gets its first line as its `title`, now at most 40 characters (cut at a word, with …); the whole text is still in the note.
- **Fixed: inbox notes listed by their file name.** With the Linter plugin's *YAML title* rule on, opening an inbox note set its `title` to the file name (`20261119_123434`), and the Inbox card then showed that. A title that is just the file name is now passed over and the card shows the note's first line.
- **Reports can be saved next to the project.** New in *Settings → Projects → Save Planning reports*: keep every report in the reports folder (as before, the default), or save it next to the project, in a `Reports` folder beside the project note (for example `1.Customers/E2I/Projects/Reports`) or inside a project folder, so a customer's reports stay with that customer. The folder name is a setting; where there is no suitable place next to the project, the reports folder is used.
- **Reports keep the project's customer and chosen properties.** A report now carries the project's customer (or Area) property, and any properties listed in *Copy into reports* (`cssclasses` by default), never its tags, status or dates, so a report never counts as a project.
