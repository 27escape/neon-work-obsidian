# Neon Work 1.1.2 — release notes

Fixes for phones and tablets.

- **No card explorer in the phone's sidebar.** On start-up Neon Work added its card explorer to the left sidebar, which on a phone is the swipe-out drawer, and with *Replace file explorer* on it closed Obsidian's file explorer. On mobile it now does neither: card explorer and graph tabs left by 1.1.0 are closed, and the file explorer is put back if it was removed. The desktop settings still apply on the desktop.
- **Desktop-only views stay light:** if a card explorer or graph tab is restored on a phone, it shows a one-line note instead of loading.
- **Start-up timing** for each part is shown in *Settings → Neon Work → Overview* (per device), to find what is slow on a phone.
