# Neon Deck 2.0.6 — release notes

Released 7 Nov 2026. To update, unzip `neon-deck.zip` and drag the `neon-deck` folder into `.obsidian/plugins/`, or replace `main.js`, `manifest.json` and `styles.css` in the existing plugin folder.

## New
- **Blackwall pattern:** an original local WebGL background with slowly wavering vertical energy cores, digital fragmentation and smoky falloff. No external artwork, assets, dependencies or network access.

## Fixed
- **24-hour time:** Neon Time's Add, Edit and Log break controls use explicit `HH:mm` input with strict validation instead of locale-dependent AM/PM display.
- **Recently done:** the activity log fills its whole dashboard widget at wide and narrow sizes while retaining internal scrolling.
- **Radar removed:** the pattern and shader are gone. Blueprint now defaults to Hex mesh, and existing saved Radar selections safely fall back to the theme default.

## Better
- **Strawberry kitten:** neutral surfaces, borders and text in dark and light modes; pink remains in accent roles, with improved foreground contrast on pink buttons.

## Verification
17 unit tests pass, static checks report no failures, and all changed UI flows were exercised in the test vault through Obsidian's debugging interface, including both Strawberry modes, Blackwall rendering, saved-Radar migration and Recently done at three viewport sizes.
