# Neon Deck 1.6.0 — release notes and check list

Released 3 Nov 2026. All five plugins (Neon Deck, Neon Tasks, Neon Tickets, Neon Time and the new Neon Write) are now 1.6.0. Everything was tested in real Obsidian with temporary notes, tickets and images, which were deleted afterwards. Time tests ran with saving switched off, and your theme was restored after theme tests.

Everything is still 100% local: no network calls, no web addresses, no remote fonts or code.

## New: Neon Write (5th plugin, optional)

Turn it off and everything behaves exactly as 1.5.0.

- **Table picker:** a rows × columns grid under the cursor (mouse, or arrows + Enter). An empty table is inserted with the cursor in the first cell, and the first row is the header. Open it from `/table`, the right-click menu or `Ctrl+P → Neon Write: Insert table…`.
- **Slash menu:** `/` at the start of a line or after a space gives tables, headings, lists, checklists, quotes, callouts, code blocks, dividers, note links and today's date. Keep typing to filter. It doesn't trigger in paths, web addresses or code blocks.
- **Toolbar on selected text:** bold, italic, strikethrough, highlight, code, note link, heading (H1 → H2 → H3 → none) and callout. Press a button again to undo it.
- **Lifted writing window:** the note sits on a rounded, raised card that grows with the pane (70% of it, 700–1020px of text).
- **Theme fonts and colours:** body text, headings and code use the Neon theme's fonts (all monospace in Phosphor). The title and H1 take the primary colour, H2 the secondary, alternating further down.
- **Images to Core/Images:** new `.png` / `.jpg` / `.jpeg` files move there automatically, and links keep working. A command moves existing ones.
- **Pattern behind notes:** the dashboard pattern, dimmed right down (35% by default, adjustable).

## Changed

**Patterns**
- **Damascus:** more variation. Two levels of folding, zones that switch between tight straight layers and loose twisted ones, and raindrop rings where the zones peak.
- **Meteorite:** no more glitches (random flashes, the sweeping band, flickering crystals). The lines bend in slow waves.
- **All dot patterns:** dots fade in as they grow instead of popping on and off.

**Graph**
- Notes only: the concept graph is gone from the view, and everything opens the note graph.

**Cards tab**
- Note cards are only a little taller than folder cards (88 vs 70px). The excerpt is one line, and the footer appears only when there are tags or links.

**Tickets tab animations**
- On opening: stat tiles rise in and count up, the done counter counts up, group headings slide in and progress bars fill.
- A new filter replays the list quickly.
- On a refresh, a new ticket slides in with a flash and a ticket whose status changed pulses. Everything else stays still.

## Fixes

1. **Pattern doubled behind every card after a reload:** right after a reload, the pattern measured the cards while they were still sliding in. Inside cards it draws brighter, so an offset outline showed behind each widget. It now redraws once the cards settle. Tested over 3 reloads: 0px off, down from up to 28px.
2. **Performance:**
   - The graph's selection ripple kept redrawing even when the graph was hidden or closed.
   - The pattern restyled the page about 20 times a second.
   - Endless pulse animations forced a restyle every frame.
   - An idle dashboard went from about 1s of JavaScript per 10s to almost none. With the pattern moving, Obsidian now uses about 2% of one CPU core. Cards, Tickets, Time, Graph and notes are all close to idle.
