# Neon Work 1.3.0 — release notes

More for PARA vaults (Projects, Areas, Resources, Archive). Existing vaults behave as before.

- **Groups from links.** *Group properties* can list several properties (e.g. `area, parent`), and a value can be a name (`photography`), a link (`[[Photography]]`), a link to any note inside the area's folder, a path, or a list of these.
- **Not groups.** Folders inside the groups folder that aren't groups (e.g. `Dailynotes, Tasks`) can be left out.
- **Project folders.** With *Project folders* set (e.g. `1.Projects`), each folder inside it is a project too, unless it already holds a tagged project note. Its status and dates come from a note named like the folder, else a note with a status. Generated notes (those with an ignored tag, such as `0.Index` notes) are only used to open the folder and are never written to; for a folder without a note of its own, the row menu offers to create `<folder>/<folder name>.md` from the project template.
- **Orphans** on the dashboard count only links from notes that aren't excluded, so generated index notes no longer hide orphan notes.
- **New note types.** New note's kinds are a table in *Settings → Neon Work → Tasks*: name, folder (`{group}` stands for the chosen group's folder), template, tag, and person (`@Name` with aliases). Older settings (meetings, people and research folders and templates) become the table automatically.
- **Areas card.** One row per group: active projects, open tasks, notes edited this month and when it was last touched, quietest first. Switch it on in *Dashboard → Areas card*; it takes the Claude card's place.
- **Inbox button in New note.** New note has an **Inbox** button: the note goes in the inbox folder (default `<base folder>/Inbox`) with the inbox tag and status (default `tags: inbox`, `status: waiting`), also when it starts from the inbox template. Quick capture's inbox notes get the same. Set the folder, tag and status in *Dashboard*.
- **Inbox card.** Inbox notes not dealt with yet (no status, or one not in the *done* list: completed, cancelled, stopped…), newest first, with an **Add to Inbox** box at the bottom. In *Dashboard → Inbox card*.
- **Dashboard order.** Inbox, Tasks and Todo are now at the top; the status cards are on the bottom row: Vault pulse below the Activity calendar, and a more compact Totals below Time today.
