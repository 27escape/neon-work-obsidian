# Neon Work 1.5.5 — release notes

- **The quick capture panel looks like a dashboard card.** The pin board / quick capture panel, and the pill on the dashboard it grows from, now use your theme's colours (card surface, text, line and shadow) instead of a glossy dark liquid, in light and dark themes alike.
- **"Capture into" uses Obsidian's own menu**, so its highlight follows your theme (the old dropdown's list was drawn by the system, with a blue highlight). Tab / Shift+Tab and Alt+1…9 still switch where it goes.
- **Several lines at once.** The panel's text box grows as you type: Enter sends, Shift+Enter starts a new line, and on the pin board each line becomes a pin.
- **Fixed: unreadable text in light themes.** The panel's input and dropdown showed light text on a light background in a light theme.
- **The Quick capture card is gone.** It repeated the quick capture panel, which is always on the dashboard; its place goes to Recently done, as it did with the card off.
- **No Search button on the dashboard.** It only opened Obsidian's own search, which is a key press away.
- **Folders starting with "_" are left out**, such as `_claude` for tools, scripts and caches: from the dashboard's stats, Recently touched and Activity calendar, from tasks, projects and Planning, and from the note graph, as excluded folders are. Switch it off in *Settings → Dashboard → Leave out folders starting with _*. The card explorer and search still show them.
