# Neon Deck 2.0.4 — release notes

Released 5 Nov 2026. To update, replace `main.js`, `manifest.json` and `styles.css` in `.obsidian/plugins/neon-deck/`.

## New
- **Prism pattern:** layered 3D cubes, some solid (lit top, darker sides) and some wireframe, in three layers that slowly drift past each other. It replaces Circuit and is the default for Cyberpunk and Night shift; a saved Circuit choice becomes Prism.
- **Complete all:** a button in a ticket's Next steps header ticks every open step at once (one log line).
- **Mark done** in a ticket draws a checkmark, then the ticket closes by itself. The done circle in the ticket list draws a little checkmark too.

## Better
- **Damascus pattern:** calm folded and twisted layers in the style of Topo, and the loop no longer jumps.
- **Dividers:** `---` is a thin line across the note that fades out at both ends. The dots and the *Animated divider dots* setting are gone.
- **Locked callouts:** clicking one in Live Preview no longer opens its source, Obsidian's edit button is hidden, and the cursor hops over it with the arrow keys.
- **Tickets:** a ticket can only be marked done once all its steps are ticked (a notice says how many are left; the done circle shakes). Ticking a step pops its box and a new log line slides in. Clicking a step's name no longer ticks it; only the box does.
- **Activity on smaller screens** (e.g. 1920×1080 at 125%): the whole month shows and the day dots stay lined up inside their cells.
