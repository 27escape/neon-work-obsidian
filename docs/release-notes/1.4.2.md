# Neon Work 1.4.2 (not released yet)

- **Plan problems, named and shown where you work.** A ⛔ that waits for an id no task has (often after folding tasks into a holding task, or a typo), one 🆔 on two tasks, or a dependency loop:
  - the Planning view names the task (for example "pla-gp2 waits for pla-sc2, but no task has that id"), and clicking the line opens the note at that task;
  - the report lists them first under *Needs attention*;
  - the project's card and row on the dashboard and Projects tab show a dashed "plan problems" pill, with the details on hover;
  - in the project note itself, the id or link is underlined while you edit, with the reason on hover. Only the display changes, nothing is written; turn it off with *Underline plan problems in project notes* (Projects settings).
- A loop is now named in order (a → c → b → a) instead of "around" one task, and another project's tasks no longer count as problems of this one.
