# Neon Deck 1.4.1 — release notes and check list

Released 3 Nov 2026. All four plugins (Neon Deck, Neon Tasks, Neon Tickets, Neon Time) are now 1.4.1. This is a fix release, mostly for Neon Time. Unlike 1.4.0, everything was tested in real Obsidian with test data, and saving was switched off during the tests so no real time was logged. The one exception is the weekend week-strip fix, which needs a weekend to see.

Everything is still 100% local: no network calls, no web addresses, no remote fonts or code.

## Changed

**Dashboard fits the window**
- The grid rows used to be fixed heights (205/250/250/230 px). They now share the visible height under the header in the same proportions. The dashboard grows on a big screen and shrinks to fit on a laptop (a 2K laptop at 150% fits entirely).
- Rows never go below 120/150/150/140 px. Below that, the page scrolls instead of squeezing the cards.
- The Time widget's entry list always keeps about two rows visible. If the card gets short, the card scrolls instead.

## Fixes (all in Neon Time)

1. **Nothing worked past 8 hours:** once a day had overtime, the ring chart crashed while drawing its overtime slice. Everything after it never appeared: the legend, the entry list and its delete buttons on the dashboard, the Time tab and Wrap up. Time looked frozen and entries couldn't be deleted.
2. **Untracked notes were still tracked:** a note's category was only checked when tracking started. Ticking `untracked` on an open note now stops tracking right away and throws away the time not saved yet. Changing a note's category saves the time so far under the old one and continues under the new one.
3. **Discarding live time deleted saved time:** when the live row continued a saved entry, "Discard live time" deleted the whole saved entry too. It now drops only the running part.
4. **Undo could be clicked twice:** this restored a deleted entry twice. Undo now works once and closes the message.
5. **Sessions past midnight:** a session running past midnight went entirely to the day it started. It's now split between the two days, and tracking carries on into the new day.
6. **Fixed "8h" and "2 minutes" text:** the Time widget subtitle and the Time Log README now follow the Workday and Idle settings. The README also explains how short bits of work add up, and it's rewritten when those settings change.
7. **Week strip on weekends:** the target line could be drawn above the bars on a weekend.

Smaller fixes:
- Enter in the time entry dialog only saves from the input fields. On a focused button (Delete, Cancel), it presses that button.
- Pausing tracking saves the leftover seconds as an entry instead of leaving them showing as live.
- The "+1h 30m over" text no longer overlaps the small ring. It shows "+1h 30m" in the accent colour.
- Entries saved when Obsidian closes are kept in time order.
