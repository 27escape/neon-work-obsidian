# Neon Work 1.4.1

- **Hotkeys for the task editor:** *Planning: edit this task*, *Planning: new task here* and *Planning: new task after this*, the items on a project note's right-click menu, are now commands too, so you can give them keys in *Settings → Hotkeys* (none are set by default). They work on the line under the cursor in a project note.
