# Neon Work 1.5.6 — release notes

- **Tidier Project details in the report.** The line under *Project details* ("From … as it stood on …") is gone, as the snapshot line at the top already gives the date, and so is the project note's own title heading, which repeated the report's title. The note's headings now start at `###`, under the report's `## Project details`, whatever level the note uses (a note with `# Title` and `## Sections` used to come out level with *Project details*).
