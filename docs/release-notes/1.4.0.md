# Neon Deck 1.4.0 — release notes and check list

Released 2 Nov 2026. All four plugins (Neon Deck, Neon Tasks, Neon Tickets, Neon Time) are now 1.4.0. They were tested headlessly with a stand-in for Obsidian: 59 automated checks, all passing, with no errors logged. The same checks run against 1.3.1 fail on exactly the 8 bugs listed under Fixes. Nothing has run in real Obsidian yet, so the list at the bottom is for that first look.

Everything is still 100% local: no network calls, no web addresses, no remote fonts or code.

## New and changed

**Dashboard**
- **Totals strip** under the grid: time worked (this month, overtime balance), days worked, tasks done, tickets done (this month, open), notes (created this month) and focus sessions. It updates whenever any plugin changes.
- **Ticker stands still:** one line of up to three facts, swapping every 10 s with a fade, paused while you hover.
- **Tasks and Global tasks** sit side by side; Tickets moved above Time today.
- **Quick capture:** Inbox removed. Task, Global, Ticket and Time remain; Ctrl+Enter sends to Task.
- **"Add a task" boxes** are clearer: tinted border, a + at the start and an accent glow when focused.
- **New tasks** slide in with a short lime glow.
- **Activity board** always fits inside its card.
- **Time widget:** a bin on each entry deletes it (with Undo).

**Sidebar navigator**
- **Contents:** folders and notes; no Recent notes list (the dashboard has Recently touched).
- **Header and indent:** inside a folder, the header shows just its name, and its contents are indented under it.
- **Colours:** folders in two shades of red, notes in two shades of acid lime; the selected note has one even green border.
- **Buttons:** New note and New folder are bigger and in the theme colours.
- **Animation:** rows slide in when you change folder, without drawing over the pane border.

**Cards tab**
- Folder cards have a soft red edge, note cards a soft lime one, fading slightly into the card over faint halftone dots.

**Tickets**
- **+ boxes:** pressing Enter shows the new entry straight away, without clicking away.
- **Steps:** edit (pencil) and remove (bin) a step; neither writes to the log.
- **Done tickets always file into Done/YYYY-MM:** also when marked done by editing the note, when a note with the same name is already there (it gets a number), and on start-up for any left behind.

**Time**
- **Time tab:** now uses the dashboard look: hero bar, rounded cards with icon headers, dot pattern, fade-in.

**Look**
- **Cyberpunk theme:** blue-black, acid yellow, cyan and hot red with sharp corners, in dark and light; Circuit pattern by default.
- **Meteorite:** livelier, with breathing crystals, a slow light sweep, glints and a faint light that follows the mouse.
- **Popups:** modals, menus, notices and previews fade in.

**Categories**
- **Ops is now Operations** everywhere: labels, the `operations: true` property and `operations_min` in Time Log notes.
- **Old values:** `ops` is still read, and existing notes were switched over once.

## Fixes

1. **Pattern animation sped up over time:** every scroll or mouse move started another animation loop, so the pattern redrew faster and used more CPU the longer the dashboard was open. It now keeps one loop at about 20 fps.
2. **Focus sessions counted twice:** a session could be logged twice if a timer tick landed while it was being saved.
3. **Listeners piled up in the Cards view:** moving it between the sidebar and a tab registered all its listeners again and left the old pattern running.
4. **Deleted time stayed in the log note:** deleting every entry for a day left them in that day's Time Log note, so your agent could have sent deleted time to Jira.
5. **Done → Waiting kept the completed date:** a ticket set from Done straight to Waiting kept its completed date.
6. **Ticking could hit the wrong line:** ticking a task on the dashboard could tick a different line if the note had changed in the meantime.
7. **The ask-on-create card could stop appearing:** after a failed note creation, it never showed again until restart.
8. **Capture popup with no targets:** with no Neon Tasks, Tickets or Time turned on, pressing Tab crashed the capture popup.

9. **Note time didn't count:** a session under a minute was thrown away whenever you switched tab, for example to check the donut, so short bursts of work never showed up. Short bursts on the same note now add up (and show in the donut straight away), a tab change that keeps the same note focused no longer resets the clock, and time under a minute is kept when Obsidian reloads. Every row in the Time tab and the dashboard widget can be deleted, including live time and short bursts not saved yet.

Smaller fixes:
- Enter on Skip in the New note card now skips.
- A failed capture keeps your text and says so.
- The ticket pop-up and Time tab let go of the pattern when Neon Deck turns off.

**Clean-up:** removed the dead Inbox code, the old scrolling-ticker styles, repeated sidebar rules, leftover section headers and a duplicate label; sped up link counting in the Cards tab.
