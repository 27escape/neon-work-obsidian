# Neon Work 1.5.2 — release notes

1.5.1 was tagged but never published, so its changes come with this release.

- **A new note opens in its own tab, ready to type.** New note on the dashboard (and the Tasks module's New note, its Inbox button, quick notes, New project and new research notes) used to open the note in the most recent tab that wasn't pinned: with a pinned dashboard it went into another tab, and the focus went back to the dashboard. A note just made now opens in a tab of its own next to the current one, so a pinned dashboard and the note you were reading stay as they are (an empty tab is used instead when that's the current one), and the cursor is in it.
- **Tabs keep their names after a restart.** A background tab saved while its part of the plugin was still loading kept the internal name, so lists such as the mobile open-files list showed "neon-deck-tickets" for Projects, or "neon-deck-cards" with a ghost icon. Once the plugin has started, such tabs are now loaded, so they get their real name and icon back; other background tabs stay unloaded.
- The dashboard's Activity pop-up counted "tickets"; it now says "projects".
- **Tidy-up:** upstream Neon Deck's 2.x release notes are gone from `docs/release-notes/` (they would have clashed with a future Neon Work 2.0), and `tools/release.sh` now links straight to a new release with the tag chosen and the title filled in when it can't make the release itself.
