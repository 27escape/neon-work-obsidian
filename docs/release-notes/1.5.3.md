# Neon Work 1.5.3 — release notes

A tidy-up after Obsidian's automated review of the plugin, which flagged style and storage warnings (no security problems). Nothing should look different; please report anything that does.

- **Styles without `!important` or `:has()`.** The dashboard grid, the Gantt chart's hover and highlighted arrows, and rows sliding out of a task list now work through CSS variables and classes set by the code, so other rules can change them without forcing. Reduced-motion settings and the Write module's note card still win over other styles, without `!important`. The old hidden flashcard blocks and the "edit block" button on locked callouts are hidden by classes rather than `:has()`, which can slow Obsidian down.
- **Settings kept per device** (safe mode, start-up checks) are stored only through Obsidian's own API.
- **Needs Obsidian 1.7.2 or later** (it was 1.5.0): the fix for tab names in 1.5.2 relies on it.
- The task editor calendar's striped days keep a fallback for older themes without a duplicate style rule, and the report's chart export resolves nested theme colours.
- A **contributing guide** (`CONTRIBUTING.md`) for reporting problems and suggesting changes.
