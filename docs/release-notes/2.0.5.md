# Neon Deck 2.0.5 — release notes

Released 7 Nov 2026. To update, unzip `neon-deck.zip` and drag the `neon-deck` folder into `.obsidian/plugins/`, or replace `main.js`, `manifest.json` and `styles.css` in the existing plugin folder.

## New
- **Manual breaks:** log a date, start time and duration in Neon Time. Breaks adjust the separate work timer without changing logged work totals; invalid ranges and overlaps are rejected.
- **Research checklist:** the Research subtab collects topics to investigate, with persistent add, check and remove controls and remaining/completed counts.
- **Template note/PDF export:** export ticket templates as editable note snapshots under `Core/Tickets/Templates`, with Obsidian PDF export. Canonical template editing stays in Neon Tickets.
- **Recently touched popup:** Recently done fills its dashboard card; the header button opens recently edited notes.
- **Strawberry kitten:** an original cream-and-pink theme in dark and light variants, without third-party artwork.
- **One-folder installer:** releases include `neon-deck.zip`, containing a single folder to drag into `.obsidian/plugins/`.

## Fixed
- **Time totals:** manually logged minutes stay exact and contribute directly to the day total and chart, independently of the work timer.
- **Ticket steps:** removing a step also removes its matching plugin-generated completion log entry.
- **Responsive dashboard:** Pulse and Totals scale to their available space without internal overflow at common monitor sizes.
- **Covered note cards:** compact cover headers no longer make cards unnecessarily tall.

## Better
- **Themes:** lighter light-mode accents with adjusted foreground contrast; neutral dark Phosphor and Blueprint cards; slightly more saturated Marathon red.
- **Date controls:** compact styling and matching light/dark native calendar controls.
- **Dividers:** `---` fades from solid on the left to transparent on the right.
- **Distribution:** the full SIL font copyright notices and license are included in the built CSS.

## Verification
14 unit tests pass, static checks report no failures, and all changed UI flows were exercised in the test vault through Obsidian's debugging interface.
