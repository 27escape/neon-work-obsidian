# Neon Deck 2.1.1 — release notes

Released 10 Nov 2026. **To update, copy only `main.js`, `manifest.json` and `styles.css` into `.obsidian/plugins/neon-deck/`.** Don't replace the whole `neon-deck` folder: it also holds your settings and module data.

## Fixed
- **Study → Research list:** adding a topic is instant (it took about 0.3 s). The add box keeps focus and anything typed meanwhile, only the list redraws, and pasting a list adds it in one go.

## Better
- **Black ICE theme:** now black and white with a dash of electric purple: black or white surfaces, a purple accent and a monochrome drifting polygon mesh. Its category colours are greys split by lightness, with purple for Projects and overtime.

## Verification
28 unit tests pass and the bug script reports no failures. Both changes were checked in the test vault through Obsidian's debugging interface (adding a topic: 276 ms before, under 1 ms after). The plugin remains 100% offline and local.
