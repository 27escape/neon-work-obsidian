# Neon Deck 1.6.5 — release notes

Released 3 Nov 2026. All six plugins are now 1.6.5. Tested in real Obsidian with temporary topics and notes, which were removed afterwards.

## Changed: the Research tab is a simple topic tree (Neon Research)

- **One tree:** topics → subtopics (as deep as you like) → notes. Topics are folders in `Learning/Core-topics`, so the tree matches Obsidian's own file list.
- **Adding:** **+ Topic** at the top; **+** on a topic adds a subtopic or a note.
- **Editing:** **⋯** (or right-click) renames, quizzes or deletes. Deleting asks first and goes to the system trash.
- **Quiz me** opens a picker: all topics or any topic or subtopic, with card and due counts. A switch quizzes every card instead of only the due ones.
- **Layout:** one header, aligned columns for counts, quiz badges and short dates, indent lines, and no hints.
- **Kept:** quiz cards (`Question :: Answer`) and link suggestions.
- **Removed:** note types, statuses, sources, topic pages and revisit.

## Fixes

- Renaming or moving a topic or note keeps its open state and quiz history; deleting forgets them.
- Changing the research folder in settings picks up that folder's quiz cards straight away.
