# Neon Work 1.1.3 — release notes

For phones and tablets.

- **No WebGL background on mobile.** The live background pattern is drawn by the graphics card as a full-pane shader; on a phone that can freeze the app while Neon Work starts. Mobile now has a plain background (desktop unchanged).
- **Start-up trace:** each start-up step is kept on the device. If a start never finishes, the next start shows where it stopped, in the safe mode notice and in *Settings → Neon Work → Overview* ("Last unfinished start on this device stopped during").
