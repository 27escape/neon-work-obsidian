# Neon Deck 2.0.0 — release notes

Released 5 Nov 2026. **Neon Deck is now one plugin.** Tasks, Time, Tickets, Research and Write are modules inside it. Everything you use works as in 1.7.0; your settings and data come along.

## Upgrade from 1.7
1. Put `main.js`, `manifest.json` and `styles.css` from this release into `.obsidian/plugins/neon-deck/` (replace the old files; the `fonts` folder is no longer needed).
2. In *Settings → Community plugins*, turn **off** Neon Tasks, Neon Time, Neon Tickets, Neon Research and Neon Write, then reload Obsidian.
3. When everything looks right, delete the five old plugin folders.

Settings and data of the old plugins are copied once into Neon Deck; the old files are not changed. Hotkeys are kept.

## New
- **Module switches** in *Settings → Neon Deck modules*. Turning a module off removes its commands, buttons and widgets at once; each module keeps its own settings tab.
- **Safe mode:** a module that fails to start stops alone. If Neon Deck itself crashed while starting, the next start keeps all modules off.
- **Safer note writes:** when a module changes a note you have open (ticking a task, a ticket log, a time note), the change goes through the editor, so your cursor and undo stay where they are. Writes to the same note happen one at a time.
- Fonts are inside `styles.css`; Quick capture has no default hotkey for new installs.

## Under the hood
- Sources in `src/` (small files, one job each), built by `tools/build.mjs` without dependencies; unit tests and a check script for local-only rules.
