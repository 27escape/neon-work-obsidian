# Neon Deck 1.6.4 — release notes

Released 3 Nov 2026. All six plugins are now 1.6.4, including the new **Neon Research**. Tested in real Obsidian with temporary notes and tickets, which were removed afterwards.

## New: Neon Research (6th plugin, optional)

Research kept apart from work, in its own **Research** tab (sidebar nav, between Time and Graph). Only notes in **`Learning/Core-topics`** count; the folder can be changed in the settings.

- **Note types:** concepts, sources and topics, from the Research tab's buttons or `/concept`, `/source`, `/topic` in any note. A short form fills in the right fields:
  - **Sources:** kind, author, year, link, read status.
  - **Concepts:** topics, seed → growing → done, source.
  - **Topics:** hub notes.

  Sources go in `Sources/`, topics in `Topics/`, concepts in the folder itself. A plain note dropped into the folder counts as a concept.
- **Topics:** a tile per topic (notes, seeds, flashcards due, last activity). A topic page lists every note in it and unlinked mentions, which you can link in one click. Back / Forward move between the overview and topic pages.
- **Link suggestions:** in a research note, the status bar offers to link mentions of other research note titles, one by one or all at once.
- **Revisit:** research notes you haven't opened for 14 days.
- **Flashcards:** lines `Question :: Answer` become cards. Study per topic or all of them: space shows the answer, then 1 / 2 / 3 for again / hard / easy. The spacing is kept in the plugin's own data.
- **Not work:** research notes are marked untracked, so Neon Time doesn't count them as work hours. There's a setting to change that.

## New: clear done tickets (Neon Tickets)

- **Clear done…** on the Done tab: all done tickets, or only those finished before this month, optionally with their screenshots and reports. Everything goes to the system trash, so it can be restored, and empty month folders are tidied away.

## Fixes (from the Neon Research test pass)

- A `::` inside inline code no longer makes a flashcard.
- Back / Forward step between the Research overview and topic pages.
- Renaming a topic keeps its open page; deleting a note forgets its revisit and flashcard history; a rename carries them over.
- Study keys work wherever focus is, and a quick double press grades once.
- Long topic names no longer overflow the header.
