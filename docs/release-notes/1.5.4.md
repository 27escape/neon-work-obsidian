# Neon Work 1.5.4 — release notes

- **Links to the plugin's tabs from your notes.** A Markdown link with an `obsidian://` address opens a tab: `[Projects](obsidian://neon-work?open=projects)`. It can open the dashboard, projects, tasks, research, time, inbox, cards or graph, or a project's plan: `open=planning&project=` with the project note's name or path (and `&mode=board`, `graph` or `list`). The new command **Copy a link to this tab** copies a ready-made link for the tab in front, to paste into a note. They work on phones and tablets too.
- **Page previews in the plugin's lists.** Hovering a note's name in the Projects tab and card, Research (the tree and By status), Tasks (the note's name beside each task, opening at its line), the Inbox and Planning's issue lines now shows Obsidian's page preview, as the file list does. Hold Ctrl (Cmd on a Mac) while hovering, or switch that off for each tab in *Settings → Page preview*, where they are listed as Neon Work projects, research, tasks, inbox and planning.
