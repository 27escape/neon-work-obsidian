# Neon Deck 2.1.0 — release notes

Released 10 Nov 2026. **To update, copy only `main.js`, `manifest.json` and `styles.css` into `.obsidian/plugins/neon-deck/`.** Don't replace the whole `neon-deck` folder: it also holds your settings and module data.

## New
- **Black ICE theme and pattern:** a graphite theme with glacial cyan and cold violet, and a background of connected triangles whose corners drift slowly, so the polygons keep re-forming. Original, drawn entirely in code.
- **Flashcard editor:** `/flashcard` opens a popup with a live two-sided preview. Add several cards in a row (Enter moves on, Ctrl+Enter inserts) and they go in at the cursor. Run it on an existing `question :: answer` line to edit that card.
- **Log time by end time:** Add time, Log break and Edit ask **From** and **Until** instead of minutes. The length shows as you type, the quick chips count back from Until, and entries may cross midnight.
- **Matching colours per theme:** every theme has its own category palette built from its accent. The Time wheel's untracked time, breaks and overtime use theme colours too.

## Fixed
- **Templates:** editing a template after changing the ticket folder no longer fails; a name clash shows a notice; the list updates at once after saving.
- **Flashcards:** Esc on an unchanged card line leaves it alone; indentation is kept.
- **Time:** editing only an entry's category keeps its exact times.
- **Locked blocks:** Ctrl+A selects the whole note when it ends with a locked block.

## Better
- **Smaller download:** fonts are embedded as compact WOFF2, so `styles.css` drops from 1.6 MB to 0.4 MB. The interface fonts now cover Latin characters; other alphabets use the system font.

## Removed
- **Blackwall pattern:** if you had it selected, your theme's default pattern is used.

## Verification
28 unit tests pass and the bug script reports no failures, with new regression checks for each fix. Every change was exercised in the test vault through Obsidian's debugging interface. The plugin remains 100% offline and local.
