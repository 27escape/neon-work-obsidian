# Neon Deck 2.0.1 — release notes

Released 5 Nov 2026. A bug-fix release on top of 2.0.0. To update, replace `main.js`, `manifest.json` and `styles.css` in `.obsidian/plugins/neon-deck/`. Coming from 1.x? Follow the upgrade steps of 2.0.0 in the git history (turn the five old plugins off, then reload).

## New
- **Research sections:** the `+` in the Research section switch adds any vault folder, or creates a new one. Right-click a section to rename it or remove it from the switch; its notes stay.

## Fixed
- **Tasks:** if a task changed in the note after the list was drawn, ticking it no longer leaves a row that looks done but isn't, and a refused edit no longer shows the unsaved text. Enter while typing with an input method (Chinese, Japanese, …) no longer saves a half-typed task.
- **Time:** after the laptop slept, the first key press no longer counts the whole sleep as work; the idle rule ends the day at the last real activity. A workday that runs past midnight is no longer ended while you are still working.
- **Research:** a note moved into a section has its quiz cards right away, not only after it is edited.
- **Activity:** the calendar updates as soon as something is done. Days older than a week show their date ("Thu 29 Oct"), so two Fridays no longer look the same.
- **Safe mode:** quick reloads no longer start safe mode by mistake. After a real crash, safe mode stays on until you turn it off in *Settings → Neon Deck modules*, and the module switches show what is really running.
- A failed note write no longer leaves an extra error in the developer console.
