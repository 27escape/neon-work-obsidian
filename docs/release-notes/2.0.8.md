# Neon Deck 2.0.8 — release notes

Released 9 Nov 2026. To update, unzip `neon-deck.zip` and drag the single `neon-deck` folder into `.obsidian/plugins/`, or replace `main.js`, `manifest.json` and `styles.css` in the existing plugin folder.

## New
- **End day:** Start day turns into End day once pressed, with Pause/Resume beside it; an ended day can be resumed.
- **Workday in the log note:** the daily log note gets a Workday section with start, end, worked time and each break.
- **/flashcard:** a slash command that turns the line into a `question :: answer` card.
- **Lockable math blocks:** `$$` blocks can be locked like callouts (stored as `$$ % locked`), in Reading view and Live Preview.
- **Study tab:** the Research tab is now called Study. Command ids, view types and saved data are unchanged.

## Fixed
- **Log break:** breaks on today no longer get a start time in the future and are accepted again.
- **Loose start times:** type `930`, `9:30` or `9.30`; the field fills in `09:30`.
- **Popout windows:** time tracking works for notes opened in their own window.
- **Research list:** a duplicate topic says it is already on the list instead of a wrong length error; the input keeps focus after Enter, and pasting several lines adds one topic per line.
- **Midnight:** an open dashboard moves to the new day.

## Better
- **Time colours:** Time tab buttons and balance numbers follow the theme accent.
- **Tickets:** titles and descriptions can be selected and copied.
- **Study motion:** subtab switches slide, and topics animate when added, ticked or removed. All motion is off when reduced motion is requested.

## Verification
26 unit tests pass and static checks report no failures. Every change was exercised in the test vault through Obsidian's debugging interface. The plugin remains 100% offline and local.
