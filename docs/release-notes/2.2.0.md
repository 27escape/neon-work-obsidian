# Neon Deck 2.2.0 — release notes

Released 12 Nov 2026. To update, replace `main.js`, `manifest.json` and `styles.css` in `.obsidian/plugins/neon-deck/` (keep the folder: it holds your module data), or unzip `neon-deck.zip` into `.obsidian/plugins/`.

## New: Pin board (Dynamic Island)
- **A ferrofluid island** that drops down from the top bar. Drag a note from the file list, a Neon card or row, a file from your computer, or some text over the top bar: the island drips down; drop on it to pin. While you drag over it, droplets rise into liquid spikes.
- **Pins live in `Core/Pin board.md`**, one line each (`- [[Note]]` or `- some text`), so you can edit the note by hand. Click a pin to open it, drag it into a note to insert the link, × to unpin. Files from your computer are copied into `Core/Pinned/`.
- **The dashboard ticker is the island at rest:** a small liquid pill that swells into the pin board when you click it, press Enter on it, or drag something over it, and shrinks back afterwards.
- **Quick capture is the island's input line:** Enter pins the text; Tab, Alt+1… or the dropdown send it to Task, Global task, Ticket or Time instead. In popout windows Quick capture stays a dialog.
- **Matches your theme:** a deep, glossy tone of each theme's own colours in dark mode, an ink-dark tone of the theme in light mode.
- **Motion:** squash-and-stretch opening, a swallow when a pin goes in, pins bubble in and melt away. Off when your system asks for reduced motion.
- New command **Toggle pin board** (no default hotkey).

## Fixed
- Dragging a note over Neon's drop targets no longer freezes the dragged file name on screen.
- Dragging Neon cards and rows into a note inserts a link in your link style.

## Under the hood
- Public Obsidian API only: file drags use plain browser drag data instead of Obsidian's internal drag manager.

## Verification
32 unit tests pass, static checks report no failures; real drags (file list → island, file list → Neon folder, Neon row → note) and every theme in light and dark were checked in the test vault.
