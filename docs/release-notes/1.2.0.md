# Neon Work 1.2.0 — release notes

Settings for vaults that aren't organised by customer, such as a PARA vault (Projects, Areas, Resources, Archive). Existing vaults keep working as before: every new setting defaults to the old behaviour.

- **Group name, property and folder** (*Settings → Neon Work → Projects*). "Customer" was built in; it is now a group you can rename (Area, Client, Team…), read from a property you choose (`customer` by default, `area` for example) or from the folder a note is in. The UI uses the name everywhere: New note, New project, the Projects tab's grouping and the timeline.
- **Several task tags** (*Tasks → Task tags*): `#task, #todo` counts both; new tasks get the first.
- **Ignored tags** (*Dashboard → Ignored tags*): notes with one of these tags in their properties (e.g. `vault_index` folder index notes) are left out of stats, tasks, projects and research.
