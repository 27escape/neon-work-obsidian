# Neon Deck 2.0.7 — release notes

Released 7 Nov 2026. To update, unzip `neon-deck.zip` and drag the single `neon-deck` folder into `.obsidian/plugins/`, or replace `main.js`, `manifest.json` and `styles.css` in the existing plugin folder.

## Better
- **Ticket step names:** plain clickable text again, with mouse, Enter and Space toggling, synchronized accessibility state and no native-button styling.
- **Popup motion:** restrained step and priority-tile hover transitions, all disabled when reduced motion is requested.
- **Complete all:** open steps animate from top to bottom before the existing single note write. Long tickets are capped at 480 ms; reduced motion completes immediately.

## Fixed
- **Ticket memory use:** settled per-note write-queue entries are removed without interfering with newer queued writes.

## Verification
20 unit tests pass and static checks report no failures. Real test-vault checks covered plain-text interaction, mouse and keyboard toggling, cascade order and timing, note contents, queue cleanup and reduced motion. The shipped JavaScript and CSS contain no network calls, remote assets or external-page opening; the plugin remains 100% offline and local.
