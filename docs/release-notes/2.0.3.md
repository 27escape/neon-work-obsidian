# Neon Deck 2.0.3 — release notes

Released 5 Nov 2026. To update, replace `main.js`, `manifest.json` and `styles.css` in `.obsidian/plugins/neon-deck/`.

## New
- **Folder colours:** right-click a folder in Cards (card or sidebar row) → *Folder colour…* to give its icon your own colour. It beats the automatic category colour, theme colours follow the theme, *Automatic* goes back. Kept when you rename or move the folder.

## Better
- **Calmer graph:** nodes are plain dots in the theme colour with a faint glow; links are thin and grey and light up only around the node you hover or pick; names show for hubs, the focus, and when zoomed in. The dimming fades in and out smoothly, also when moving straight from one node to the next.
- **Cards look:** note cards have a soft edge glow instead of a dotted one; PDFs, DOCX and images just a border; folder dots are fainter and only toward the right edge.
- **Recently done / touched:** the done list gets most of the card; the touched notes below it show the latest 4.
- **Time:** Start, Pause and Resume day respond at once.
