# Neon Deck 2.0.9 — release notes

Released 10 Nov 2026. **To update, copy only `main.js`, `manifest.json` and `styles.css` into `.obsidian/plugins/neon-deck/`.** Don't replace the whole `neon-deck` folder: it also holds your settings and module data.

## New
- **Ticket templates are notes:** each template is a note in `Core/Tickets/Templates`, and the note is the template. The Templates tab, the New ticket picker and PDF export all use the notes; edit a note directly and the template changes. The folder is created on start, and templates saved in plugin data move into notes once (the old list stays as a backup).
- **Save as template:** right-click a ticket → **Save as template…** opens a new template filled with its steps, description, priority and due offset.

## Fixed
- **Templates lost on update:** templates now live in the vault, not the plugin folder, and the README's update steps no longer say to replace the folder.
- **Workday counts:** with Start day / End day, the day total is the larger of logged time and the workday timer (minus breaks). The difference shows as a grey **Untracked** slice. Balance, status bar and log notes follow (`untracked_min`, `break_min`).
- **Breaks on the wheel:** breaks get their own blue slice and a legend row and are never counted as worked. Log break without a start time now ends where work stopped (an open pause or End day) instead of being rejected.
- **Locked math blocks:** clicking a locked formula in Live Preview no longer opens its source, and the cursor skips over it.

## Verification
28 unit tests pass and static checks report no failures. Every change was exercised in the test vault through Obsidian's debugging interface, including real clicks on locked formulas. The plugin remains 100% offline and local.
