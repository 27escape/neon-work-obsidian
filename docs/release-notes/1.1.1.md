# Neon Work 1.1.1 — release notes

Fixes for using Neon Work on more than one device.

- **Safe mode is per device.** The start-up check (which turns on safe mode when the plugin crashes while starting) used a flag in `modules.json`. When `.obsidian` is synced (Remotely Save, Obsidian Sync, iCloud…), a start on one device could put another device into safe mode. The check and the safe mode switch now live on each device and are never synced, and it takes two unfinished starts in a row (closing the app once during start-up no longer counts). Older `starting` / `safe` values in `modules.json` are ignored and dropped.
- **Last start-up error** is shown in *Settings → Neon Work → Overview*, since phones have no developer console.
- **Fewer synced writes:** starting the plugin and switching settings sections no longer rewrite `modules.json`.
- **Time log:** with the log folder left empty, the folder (`<base folder>/Time Log`) is now created, so the day's note is saved instead of failing.
