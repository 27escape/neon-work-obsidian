# Neon Deck 1.7.0 — release notes

Released 5 Nov 2026. All six plugins are now 1.7.0. Everything was tested in real Obsidian with made-up data, which was removed afterwards. Saved settings and data from 1.6.5 are kept.

## New

- **Work Time tracker (Time):** Start day / Pause / Resume in the Time widget and tab. The clock keeps running while Obsidian is idle or closed; after 2 h without input the day ends at your last activity (setting). Wrap up ends the day. On screen, tracked time is scaled to the time worked; the Time Log files keep the times as logged.
- **Sections in Research:** Research and School (or any folder) each get their own tree, quiz counts and card history. Switch at the top of the tab; edit them in settings.
- **Add flashcard:** a button in the header of research notes and a command; a small Question / Answer form that stays open.
- **Recently done / touched (Deck):** ticked tasks and tickets set to Done or Waiting, grouped by day, above the recent notes. The Quick capture card is off by default (the command and `Ctrl+Shift+Space` still work).
- **Activity (Deck):** a month view (stats and a calendar) and a view per week; click a day for a pop-up with everything that happened.
- **Write:** lime dotted dividers (`---` under text stays a divider), small sub-titles (`####`, toolbar, `/sub`), page breaks for PDF export (`/pagebreak`), lockable callouts (click the lock; `[!info|locked]` in the note), merged table title rows (`| Title | < | < |`, Reading view and PDF).
- **Tickets tab:** sort or group by due date, status, priority, newest, oldest, recently changed, title, ID or Jira key.
- **Edit tasks** from the dashboard (pencil on hover); global tasks still edit with a double-click.
- **Sidebar:** notes and folders starting with `!` stay on top; the rest sort by the `created` property.

## Changed

- **Tasks widgets are instant:** a new task shows at once, only changed rows update, and rows animate in and out.
- **Research tab is faster:** folders open in place, typing in a note no longer redraws the tree.
- **Themes:** Brutal is removed (a saved Brutal opens as Marathon); all themes use the same rounded corners; Blueprint and Phosphor are calmer with colour only in the accents; glows only on active items.
- **Time tracking** keeps counting while you are briefly in another app; after 30 min without input in Obsidian it ends at your last activity.
- **Ticket reminders** stay inside Obsidian. Desktop (system) notifications are gone: on Linux they froze Obsidian for about two minutes.
- Ticket log: newest entry on top everywhere. Time tab: newest entry on top.

## Fixes

- Time: a running entry can be deleted (it used to come back); `Untracked`, `untracked: True` and `#untracked` now stop tracking.
- Format bar: Bold / Italic / Strikethrough toggle on and off cleanly (Italic no longer turns bold text into italic).
- Ticket steps: one file write per tick, shown at once; fast ticking no longer clashes.
- Saving on quit (Deck, Research), a quiz that froze when a save failed, settings from newer versions kept, the graph panel cut off by the status bar, Vault pulse tiles clipped on hover, and a Time day note rewritten while you typed in it.
